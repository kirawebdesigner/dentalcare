# DentalCare Sale Assets

This folder contains clean screenshots captured from the live deployment at [dentalcare-1.web.app](https://dentalcare-1.web.app/) on 23 August 2026. The screenshots are intended for buyer review and SideProjectors listing materials.

No screenshot contains a password. The live demo data is intentionally empty: the images show the product surfaces and role navigation without real patients, appointments, payments, or medical records.
